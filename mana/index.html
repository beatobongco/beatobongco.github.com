    Ready for the table

    Tap either button to add or spend one mana. Hold either button to add or spend three every second until you release; releasing adds nothing extra. Minus stops at zero. Undo reverses a grouped burst of taps or a whole hold in one action. The activity log shows newest changes first and keeps the latest 200 entries; Undo marks the original entry as Undone. Reset clears mana and recent activity; Undo can restore the mana, but cleared activity stays cleared. Clear history only clears the activity log. Same-direction taps accumulate for three seconds; then the badge dims. The next tap starts a new adjustment. Undo restores your last action, including Reset or removing a pool.

    Install & use offline

    Open the hosted app once while online. On iPhone or iPad: Safari → Share → Add to Home Screen. On Android or desktop: use your browser’s Install app option. Wait for “Ready offline” before leaving the network.

    Download a standalone HTML copy — open the saved file in a browser without internet. Home-screen installation requires the hosted HTTPS version.

    Your pool and appearance are saved in this browser. Clearing browser data removes them. Offline copies and the hosted app have separate saved state.
